# qHdrImageViewer 1.2.2 — VSR 交互、缩放插值拆分、方向键切换

本版本对应四项使用反馈：RTX VSR 开关语义、右键菜单 VSR 交互与取景稳定性、放大/缩小插值算法拆分、左右方向键切换图片。产物为 **qHdrImageViewer 1.2.2.0**。

## 1. 设置里的 RTX VSR 开关改为“右键菜单开关”

- 新设置 **「启用 RTX VSR（右键菜单）」**（内部键 `RtxVsrMenuEnabled`，默认开启）只控制图片右键菜单里是否出现 **「RTX VSR 超分」**：
  - 开启：右键菜单显示该项（若本机没有 NVIDIA VSR 运行库则置灰）。
  - 关闭：该项从菜单中隐藏；若当时正在显示 VSR 结果，会自动恢复原图。
- **不再“默认对所有图片应用 VSR”**：删除了打开图片时自动套用 VSR 的逻辑；VSR 只在你从右键菜单点击时执行。
- 升级说明：旧的 `RtxVsrEnabled` 字段（原“自动应用”语义）不再读取，新开关默认开启，所以升级后右键菜单就能看到 VSR（不会因旧值而被隐藏）。

## 2. 右键菜单 VSR 交互与“取景不变”

- 移除「显示原图」菜单项；「RTX VSR 超分」不再是勾选式开关，而是一个普通动作项：
  - 未启用时显示 **「RTX VSR 超分」**；
  - 已启用时显示 **「关闭 RTX VSR 超分」**。
- **处理前后图像位置与缩放完全不变**：开启 VSR 时不再重置缩放模式、缩放比例或滚动位置（之前会重新居中并可能改变实际大小模式），关闭时同样保持原位。这样在同一位置反复“开启/关闭”即可直接对比增强前后的细节。
- 状态栏仍显示增强后的像素尺寸（如 `PNG · 3200 × 2000 … · RTX VSR 2×`），缩放百分比保持与开启前一致（例如 82.5% 始终显示 82.5%）。
- 应用成功仍会显示提示：`RTX VSR 已启用：3200×2000，…ms` + 「放大图片查看细节；再次点击右键菜单的“关闭 RTX VSR 超分”即可对比开启前后的差异。」

## 3. 缩放插值拆分为“放大/缩小”两套算法

设置页「查看器 → 缩放」现在有两个独立选项：

| 设置 | 生效条件 | 选项 |
|---|---|---|
| 放大插值（>100%） | 图片显示尺寸大于原始像素（放大显示） | 自动 / 最近邻 / 双线性 / 双三次 / Lanczos |
| 缩小插值（<100%） | 图片显示尺寸小于原始像素（缩小显示） | 自动 / 最近邻 / 双线性 / 双三次 / Lanczos |

- 方向由像素着色器根据实际采样率自动判断（1 显示像素 > 1 源像素 = 放大；反之 = 缩小），无需手动切换；100% 时走“缩小”档（与旧行为一致）。
- 两档默认均为「自动」，保持与上一版完全相同的渲染（已逐像素验证：两种 Auto 在 200% 与 50% 下与旧版输出完全一致）。
- 旧设置文件里的单个 `ZoomInterpolation` 值会在升级时迁移到这两个新选项，旧字段在下次保存后消失。

## 4. 左右方向键直接切换图片

- **←/→** 现在始终切换到上一张/下一张图片；**Home/End** 跳到文件夹首张/末张。
- 修复了“胶片栏有键盘焦点时方向键只移动胶片栏选中、不切换图片”的问题：窗口级兜底处理会接管被胶片栏消费的方向键，同时胶片栏本身不再抢占 Tab 焦点。
- 输入框、滑块、下拉框获得焦点时仍保留原来的方向键行为（不会误切换图片）。

## 5. 安装

安装包位于 `artifacts\release\1.2.2.0\`（MSIX 108.1 MB，便携 zip 65.0 MB，内置完整编解码器）：

```
qHdrImageViewer_1.2.2.0_x64.msix              安装包（自签名，包标识 LinYuSen.qHdrImageViewer）
qHdrImageViewer-signing.cer                   自签名证书
install.ps1                                   一键信任证书并安装（需要一次管理员授权）
INSTALL.md                                    说明
qHdrImageViewer-1.2.2.0-win-x64-portable.zip  免安装便携版
BUILD_INFO.txt                                版本/签名摘要
screenshots\                                  安装后实测截图
```

右键 `install.ps1` →「使用 PowerShell 运行」，或按 `INSTALL.md` 手动信任 `.cer` 后双击 MSIX。包标识未变，可直接覆盖升级。

  - ←/→ 与 Home/End 直接切换图片；胶片栏获得焦点后 ←/→ 仍切换图片（`installed-1.2.2-04-arrow-navigation.png`）。

## 7. 已知限制

- RTX VSR 运行库因 NVIDIA 许可限制不随包分发（本机从 ComfyUI 的 `nvvfx\libs` 自动发现）。
- 去噪 / 去模糊按 NVIDIA 文档为原分辨率处理，不会放大；标准超分 / 高码率模式才按 2×/4× 输出。
- 100% 显示时使用“缩小插值”档（与旧版统一行为一致）。
