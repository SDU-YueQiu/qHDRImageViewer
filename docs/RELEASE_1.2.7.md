# qHdrImageViewer 1.2.7 — 小图缩放不再抖动/闪烁

本版修复「图片小于窗口时缩放会奇怪抖动」，并把缩放期间的背景来源统一成一条路径，产物为 **qHdrImageViewer 1.2.7.0**。

## 原因

1.2.6 之前，图片小于预览时用「图片大小的交换链宿主」，缩放动画期间再临时切成「预览大小的宿主」。这条切换链有两个问题：

- 每次切换都要 `ResizeBuffers` 并重新布局，合成器会有一帧呈现半成品（空白或旧尺寸），表现为**抖动/闪一下**；
- 动画期间铺满预览时，图片之外由**交换链清屏色**填充，动画结束又改由 **XAML 背景层**填充。两条渲染路径无法逐帧完全一致（HDR 显示上尤其明显），表现为**回闪**。

上一版尝试“动画期间也保持图片大小宿主”，结果每帧都要改宿主尺寸 + 重新布局 + 重建交换链缓冲，抖动反而更明显。

## 修复：交换链始终铺满预览，背景只由 GPU 绘制

`CreateSwapChainHostLayout` 现在**永远**返回预览大小的宿主，图片由着色器按 `ImageLayout`（缩放/偏移）绘制在里面：

- 缩放、平移都不再改变宿主尺寸 → **不再有 `ResizeBuffers`、不再有逐帧布局** → 无抖动、无空白帧；
- 图片以外的区域**始终**是交换链清屏色（背景设置），不会在动画中途切换来源；
- 清屏色按显示器 SDR 白点缩放（`linear(sRGB) × SDR白点/80`），HDR 显示下与背景设置的颜色观感一致；
- Direct2D 基础图路径的两处清屏也改用同一颜色，SDR/HDR 图片的大背景一致。

设置页「外观与语言 → 查看器背景」的选择（窗口颜色/黑/深灰/中灰/浅灰/白）依旧立即生效，现在它同时决定 GPU 清屏色与 XAML 背景层（后者在无图/回退路径可见）。

## 验证（1650×1050 窗口，300 ms 动画，约 40 ms 一帧）

| 场景 | 结果 |
|---|---|
| 400×300 小图滚轮放大 | 8 帧内图片 400×300 → 440×330 单调变化，四周采样**每帧相同**；修复前第 1 帧整帧空白、随后清屏色与 XAML 背景色来回跳 |
| 背景=黑色 | 全部帧四周 (0,0,0) |
| 5568×2225 全景放大 | 图片平滑放大，上下留白每帧相同；无回闪 |
| 小图拖到一边再放大 | h=0% v=0% 保持，背景不再变化 |

单测 639 通过 / 1 跳过（清屏色与调色板逻辑的测试保留）。
